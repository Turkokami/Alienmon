# Neonis surface textures
CC0 photo textures from Poly Haven (polyhaven.com, CC0), resized to 1024 px webp:
- nn_grit: concrete_wall_008 (desaturated, low frequencies removed) — fine grit on props and facades
- nn_pmet: rusty_metal_02 (part desaturated) — worn painted metal
- nn_gran: granite_tile — fountain stone
- nn_wave_n: three.js waternormals (MIT) — moving water ripples
