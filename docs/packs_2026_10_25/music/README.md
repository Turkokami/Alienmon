# Alienmon music pack: 14 world themes + 9 special tracks

Today every world plays the same overworld song ("Save the Stars"). This pack gives each world its own theme, plus tracks for
Keeper and legendary battles, Recovery Bays, caves, space flight, victory, evolution and Signal Dive.

## How to make them
These prompts are written for an AI music generator (for example Suno or Udio; ChatGPT does not make music).
1. Paste one prompt per track. If the tool takes an audio reference, attach `reference_save_the_stars.mp3` so every track sounds like the same game.
2. Pick the best take. It must be **instrumental** and should **loop cleanly**.
3. Save as MP3 with the exact file name. Send them in one or two zips.

When they arrive each world plays its own theme, and the special tracks play in their moments.
