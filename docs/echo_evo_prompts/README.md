# World-Echo evolutions: ChatGPT prompt pack

The 14 World-Echo forms evolve like their originals. These are their evolved Echo forms: the normal evolution's body,
in the Echo's world style. Some lines have two stages (for example Pebblet (Glacia) -> Bouldron -> Orbitusk).

## How to render
1. Open a **new ChatGPT image chat** for each form.
2. Attach **both** reference images named in its file: the normal evolved Alienmon (body) and the finished stage-1 Echo (world look).
3. Paste the **front** prompt, generate; then paste the **back view** prompt in the same chat, generate.
4. Save with the exact names, one folder per form, like the earlier packs.
5. Check: still clearly the evolved Alienmon (same body and face), with the Echo's colours and details. White background, nothing cut off,
   no text, no ball or capsule emblems. **Open each saved file once before zipping**: three Echo files last time were cut off.
