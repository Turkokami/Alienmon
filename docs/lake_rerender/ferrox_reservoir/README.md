# Ferrox reservoir re-render pack

Coolant Reservoir (880) and Reservoir Islands (881) were one big painting of water, so on foot you only had a thin strip of
shore. These two re-renders turn them into proper walkable maps: paths and catwalks out to grassy islands, wild-grass patches,
docks for the Bubbub Ride, and the two maps now join each other (Coolant Reservoir's left edge meets Reservoir Islands' right edge).

## How to render
1. New ChatGPT image chat per map.
2. Attach the **layout guide** and the **Ferrox style reference** from `references/`.
3. Paste the prompt. Generate at **1536x1024**.
4. Check that paths, catwalks and islands sit where the guide puts them, and the edge paths reach the image edge.
   It doesn't need to be pixel-perfect: I'll trace the walkable map from your finished art.
5. Save with the exact name and send both in one zip.
