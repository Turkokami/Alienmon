# World-Echo forms: ChatGPT prompt pack

Seedpods from the original Ystra fall scattered across all 14 worlds. Some Alienmon landed far from their usual home
and adapted. These are their **World-Echo forms**: the same Alienmon, recognisable at a glance, reshaped by another world.
This first set has one Echo for each world.

## How to render
1. Open a **new ChatGPT image chat** for each Echo.
2. Attach the original's sprite from `references/`.
3. Paste the **front** prompt. Generate. Then paste the **back view** prompt in the same chat. Generate.
4. Save as the names given, one folder per Echo, like the Holopup packs.
5. Check: it must still read as the original Alienmon (same body and face), with only colours, surface and details changed.
   White background, nothing cut off, no text, no ball or capsule emblems.
