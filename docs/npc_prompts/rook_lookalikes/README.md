# Rook lookalikes: re-render pack

Seven of the new townsfolk came out with spiky red hair and blue goggles, like Rook, so players could mistake them for themselves.
Each prompt keeps the character's outfit and job and only redesigns the head.

## How to render (2 renders each, 14 in total)
1. New ChatGPT image chat per character.
2. Attach the character's `_current.png` and `ROOK_do_not_copy.png` from `references/`.
3. Paste the front prompt, generate; then the back prompt in the same chat, generate.
4. Save with the exact names (front and `_up` back), open each file once, and send them in one zip.
