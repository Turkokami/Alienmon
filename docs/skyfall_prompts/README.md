# Skyfall art: ChatGPT prompt pack

Art for the new Skyfall features. Until these exist the game draws simple shapes, so everything already works without them.

## How to render
1. Open a **new ChatGPT image chat** for each file.
2. Attach `references/overworld_reference.png` so the style matches the maps.
3. Paste the prompt. Generate. Save with the exact file name.
4. Check: white background, frames the same size in every cell, nothing touching a cell edge, no text,
   no ball or capsule shapes.
