Pixel art for the Alienmon game, matching the attached reference screenshot's style: crisp pixel art, bold dark outlines, soft cel shading, top-down 3/4 view like the overworld maps. A sprite sheet of a Skyfall seedpod lying on the ground: the alien seedpods that fell from the dying world Ystra. Canvas 1024x256: four frames in a row, each in an equal 256x256 cell, the pod centered at the same size and position in every cell, its base on the same line near the bottom.
