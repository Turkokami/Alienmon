# Sporix and Gloopa versions of the story pictures (42 renders)

21 story pictures were only drawn for Plazmo players, so anyone who picks Sporix or Gloopa misses them (they get words only).
Each prompt redraws the Plazmo picture with the partners swapped. For a Plazmo player Kit has Sporix and Sola has Gloopa;
for a Sporix player the hero has Sporix, Kit has Gloopa, Sola has Plazmo; for a Gloopa player the hero has Gloopa, Kit has Plazmo,
Sola has Sporix. The prompts spell this out per picture.

Do one starter at a time if you like (all `_sporix` first). New chat per picture, attach the listed files, save with the exact name.
