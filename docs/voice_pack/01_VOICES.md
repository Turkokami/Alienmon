# Voice casting: one voice per character

**Match the Alienmon book first.** Book 1 already has an audiobook. If its voices were made in ElevenLabs (or you have the narrator/actor voices), REUSE THOSE EXACT VOICES for the same characters so the game sounds like the book. Only design a new voice for characters that are not in the audiobook. Every description below is built from how the book describes the character.

How to make a new voice in ElevenLabs: Voices > Add a new voice > **Voice Design** > paste the description > use the sample line as preview text > pick the best of the 3 > save it with the character's name.
