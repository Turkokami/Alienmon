# World expansion pack: 2 new areas on every world (28 maps)

Each new area hangs off a quiet dead-end map, so exploring pays off: every world gets a story-flavoured landmark (the Seedpod
Dig Site, the Spore Choir Amphitheatre, Shipwreck Cove, the Lantern Festival Street, the Hall of Champions...) with tall grass
for wild Alienmon. When the art comes back I trace each map, join it to its neighbour, fill it with that world's wild Alienmon,
townsfolk and a stash or two, and can hang side quests off them.

## How to render
New chat per map. Attach the **entrance** image (where the path must meet the edge) and the **style** image (the neighbouring
map, so it looks like the same world). Paste the prompt, generate at 1536x1024, save with the exact name. Send a few per zip.
