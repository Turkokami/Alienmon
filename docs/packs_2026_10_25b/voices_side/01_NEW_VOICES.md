# Voices for side quests and Keeper battles

Reuse the voices you already made for the main story (same names). Only these are new:

## Explorer (townsfolk)  (`explorer`)
```
Adult adventurer: upbeat, outdoorsy, encouraging.
```

## Kid (townsfolk)  (`kid`)
```
Excited little kid about 8, bright and breathless.
```

## Mina  (`mina`)
```
Girl about 11: bossy, brave, teasing dock kid, quick and cheeky, says "landlubbers".
```

## Miner (townsfolk)  (`miner`)
```
Adult miner: hearty, gravelly, cheerful working voice.
```

## Pilgrim (townsfolk)  (`pilgrim`)
```
Soft-spoken, peaceful pilgrim of the sky temples.
```

## Researcher (townsfolk)  (`researcher`)
```
Adult scientist: curious, precise, friendly and a bit nerdy.
```

## Scrapper (townsfolk)  (`scrapper`)
```
Scrappy Ferrox junk dealer, fast-talking and cheeky.
```

## Squid Sailor  (`squid`)
```
Jolly old sea-captain creature voice, warm and bubbly, says "ahoy, matey". Not a human accent parody; friendly and kid-safe.
```

## Technician (townsfolk)  (`technician`)
```
Adult worker, practical and friendly, a little hurried, everyday tradesperson voice.
```

## Wanderer (townsfolk)  (`wanderer`)
```
Calm traveller, laid-back and thoughtful.
```
