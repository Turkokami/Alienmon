# Side quests + Keeper battle voices (ElevenLabs)

The next voice batch after the main story: all 49 side quests, plus every Keeper's battle intro, defeat and after-battle line.
213 files. Same steps and rules as the main-story pack: match the Alienmon book voices, keep the main-story voices for
characters already recorded, generate each line, save with the exact file name, send in zips.

- `01_NEW_VOICES.md`: Voice Design descriptions for the townsfolk voices that are new in this batch.
- `scripts/`: lines per quest in order. `all_lines.csv`: everything in one table.
- Lines that say the starter's name come in three versions (`_sporix`, `_plazmo`, `_gloopa`).
