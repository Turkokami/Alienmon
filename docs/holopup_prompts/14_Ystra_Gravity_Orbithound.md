# 14 Orbithound: Ystra (Gravity)

- **Evolves from:** Holopup, using the Signal Shard of Ystra
- **Type:** Gravity
- **Attach:** `Holopup_reference.png`
- **Save as:** `Orbithound.png` (front) and `Orbithound_back.png` (back)

## Front prompt
```
Pixel-art creature sprite for the Alienmon game. Match the attached reference image (Holopup) exactly for art style: crisp pixel art, the same pixel size and density, bold dark outline, soft cel shading and the same glowing hologram feel.

Design: "Orbithound", the Gravity-type evolution of Holopup that appears when it is attuned to the Signal Shard of Ystra (a shattered homeworld planet). Keep it clearly part of the Holopup family: the same friendly fox-puppy face, big eyes, large expressive ears, fluffy tail and the round collar ring, but grown up into a sleeker, slightly taller adult (the size of a stage-2 evolution).

What changes for Ystra: Deep indigo and starlight-silver. Small floating rock fragments orbit its body and a thin planet-ring circles its waist. It stands slightly off the ground, as if gravity bends around it.

Pose: the same 3/4 front standing pose and facing direction as the reference.

Canvas 1024x1024, square. Pure flat white #FFFFFF background. One creature, centered, filling about 75% of the canvas, nothing touching the edges. No ground, no cast shadow, no scenery, no text, no labels, no logo, no border. No ball, capsule or round "catch device" emblem anywhere on the design.
```

## Back view prompt (same chat, after the front)
```
Now draw the SAME creature from behind (back view, looking slightly over its shoulder), same design, colors, size and pixel style. Same canvas rules: 1024x1024, pure flat white #FFFFFF background, centered, about 75% of the canvas, no shadow, no text.
```
