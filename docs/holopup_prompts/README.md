# Holopup world evolutions: ChatGPT prompt pack

Holopup becomes Alienmon's "Eevee": use a world's Signal Shard on it and it evolves into that world's form.
There are 14 worlds and exactly 14 types, so every world gets its own type with no repeats.

## How to render
1. Open a **new ChatGPT image chat** for each form.
2. **Attach `Holopup_reference.png`** (in this pack) so the style matches the game.
3. Paste the **front** prompt from the form's file. Generate.
4. In the same chat, paste the **back view** prompt underneath it. Generate.
5. Save the two images as `<Name>.png` (front) and `<Name>_back.png` (back).
6. Check: white background, whole creature visible, nothing cut off, no text, and no ball or capsule emblems.

Start with `00_base_Holopup.md` only if you want a plain, un-attuned Holopup. The current Holopup art can stay as the base.
