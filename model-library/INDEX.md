# Alienmon model library

Every Alienmon model in one place, one folder per creature, on the `model-library` branch only. Nothing here is used by the live game.

- **_overworld.glb**: the model that walks around the map.
- **_battle.glb**: the battle model the game uses now.
- **_battle_rig.glb**: rare creatures' battle rig, copied from Squatch Studio storage.
- **source/**: the original Squatch Studio model it was made from.
- **rigged/**: the new rigged copies with the fluid moves, added as each one passes its checks.

Status is the new-rig check: moves that pass the tear, floor, pop, loop-seam and foot-slide checks.
